# Spice Rail — Food Order Management (Frontend)

React front-end for the Food Order Management System. Ticket-rail themed UI: dashboard with live charts, a kitchen-ticket order list, order creation flow, and menu catalogue management.

## Stack
- React 18 + React Router
- react-bootstrap (grid + modal) + Bootstrap 5 base
- Chart.js / react-chartjs-2 for dashboard charts
- Axios for API calls
- react-icons (Lucide set)
- Custom design tokens (`src/styles/tokens.css`) — Fraunces / Inter / JetBrains Mono, charcoal + mango + basil palette


Make sure the backend is running (see the backend README) and seeded with `npm run seed` so you have a login and demo menu.
